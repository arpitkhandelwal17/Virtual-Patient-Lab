# engine — the calculator

Drug-level maths and population logic. No web code and no database code lives here.

**Belongs here:** blood-level model, repeated dosing, person adjustments (weight, age, kidney, liver, genotype), virtual population generation (fixed seed), risk flags, interaction checks, uncertainty analysis.

**Does not belong here:** web pages, database access, fetching from DailyMed/openFDA/PubMed.

Every calculation here has a test in `tests/engine/`.
